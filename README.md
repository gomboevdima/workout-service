# Workout Service

Учебный проект на Python для освоения backend-разработки.

## Возможности

- Создание тренировок с проверкой данных и уникальности ID.
- Поиск тренировки по ID.
- Изменение веса и удаление тренировки.
- Расчёт объёма: вес × повторения.
- Подсчёт общего объёма тренировок пользователя.
- Поиск максимального веса для выбранного упражнения.

## Структура

- `workouts.py` — логика работы с тренировками.
- `test_workouts.py` — девять тестов.

## Запуск тестов

Из папки проекта:

```bash
python3 test_workouts.py
```

При успешном выполнении появится сообщение:
`Workout tests passed successfully`.
